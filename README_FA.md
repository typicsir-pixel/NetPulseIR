# NetPulse IR — نسخه اولیه اندروید

این پروژه اسکلت اولیه یک اپ مستقل اندروید است:
- سرویس Foreground برای ادامه پایش هنگام خاموش بودن صفحه
- تشخیص VPN از طریق Android ConnectivityManager
- شناسایی شبکه‌های Wi-Fi و Cellular در دسترس
- تست HTTPS به endpoint عمومی Cloudflare و اندازه‌گیری زمان پاسخ
- ویجت صفحه اصلی که آخرین نتیجه را نمایش می‌دهد

## ساخت
پروژه را در Android Studio باز کنید و با Gradle Sync بسازید:
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.6.1
- Kotlin 2.0.20

سپس از Build > Build APK(s) خروجی بگیرید.

## نصب و راه‌اندازی
1. APK را روی گوشی نصب کنید.
2. مجوز اعلان را بدهید.
3. برنامه را باز کنید و «شروع پایش پس‌زمینه» را بزنید.
4. صفحه اصلی گوشی را نگه دارید > Widgets > NetPulse IR و ویجت را اضافه کنید.
5. برای پایش پایدارتر، در تنظیمات باتری سامسونگ برای برنامه محدودیت پس‌زمینه را بردارید و آن را در فهرست برنامه‌های Never sleeping قرار دهید.

## محدودیت‌های مهم این MVP
- این نسخه سورس پروژه است، نه APK امضاشده و آماده نصب.
- Android و سازنده گوشی ممکن است سرویس پس‌زمینه را به علت مدیریت باتری متوقف کنند.
- ویجت با آخرین نتیجه‌ای که سرویس گرفته به‌روزرسانی می‌شود؛ سیستم‌عامل تضمین رفرش دقیق و ثانیه‌ای ویجت را نمی‌دهد.
- اگر VPN روشن باشد، Android آن را تشخیص می‌دهد؛ اما مسیر دقیق هر درخواست به تنظیمات VPN و split tunneling بستگی دارد. در این حالت نباید نتیجه را قطعاً «مسیر مستقیم ایران» تفسیر کرد.
- زمان HTTPS جایگزین ping ICMP نیست. Packet loss و jitter واقعی در این نسخه هنوز محاسبه نمی‌شوند؛ برای آن‌ها باید چند probe زمان‌بندی‌شده و روش اندازه‌گیری مجزا اضافه شود.
- بررسی Wi-Fi و Cellular فقط وقتی ممکن است که سیستم‌عامل آن شبکه را در اختیار برنامه قرار دهد. شبکه غیرفعال/غیرقابل‌دسترسی ممکن است قابل تست نباشد.
- هیچ داده‌ای به سرور یا DV Guard ارسال نمی‌شود؛ نتایج در حافظه محلی برنامه ذخیره می‌شوند.


## ساخت خودکار APK با GitHub Actions
1. فایل ZIP پروژه را استخراج کنید.
2. یک مخزن جدید در GitHub بسازید و تمام محتویات پوشه پروژه (از جمله پوشه مخفی `.github`) را در آن بارگذاری کنید.
3. در GitHub وارد زبانه Actions شوید و workflow با نام **Build NetPulse IR APK** را اجرا کنید؛ با push به شاخه main نیز خودکار اجرا می‌شود.
4. پس از پایان موفق، در صفحه اجرای workflow بخش **Artifacts** فایل `NetPulseIR-debug-apk` را دریافت کنید.
5. APK را روی گوشی نصب کنید. این خروجی debug است و برای انتشار عمومی باید نسخه release امضاشده ساخته شود.

نکته: اجرای GitHub Actions به حساب GitHub و دسترسی آن به Actions نیاز دارد.
